Genome graph indexing

gfaidx

Fast and on-demand access to indexed genome graphs.

View gfaidx on GitHub

Query any region fast.

gfaidx indexes genome graphs so a query can retrieve a subgraph quickly and efficiently, without first loading the complete graph into memory.

Instead of treating a large GFA as one file that must be loaded all at once, gfaidx keeps it in queryable indexed chunks. A request reads only the relevant graph neighborhood.

Interactive graph visualization

The graphviz_wasm frontend is based on BandageJS, a WebAssembly version of BandageNG for web browsers. Its backend is part of the MMseqs2 app API. This lets the visualizer request a subgraph for any query, then render the returned result on demand.

Try the live graph visualizer

The frontend currently includes only a couple of example graphs. Once the server has been migrated to fast NVMe storage, fully indexed HPRC version 2 graphs will be available for visualization and API requests.

Integration into BandageNG

The gfaidx API is being implemented in BandageNG. The integration is not yet complete, but an initial implementation is available in the repository.

The goal is that when an indexed graph is opened in BandageNG, the complete graph does not need to be loaded into memory. Instead, a user can request a subgraph by node or genomic region and have the result visualized directly in BandageNG.

Help shape these tools

gfaidx and its integrations are under active development. Feedback from people using the tools is very welcome.
